# V2 photo sources

The `/v2` marketing page uses three photo groups:

- Vemi field-audit evidence from `public/audit/` for trust evidence and the
  competitive-intelligence service.
- Free-to-use Pexels photography for subjects not represented in the current
  field library. These files are downloaded and served locally rather than
  hotlinked.
- Iraq-specific editorial retail photography for the FMCG action examples.
  These images are for local design review only and require written usage
  permission before the site is published.
